Abstract

Exploratory data analysis (EDA), data quality assessment, and machine learning problem formulation represent essential yet time-intensive initial phases of the data science lifecycle. In professional and academic settings, practitioners routinely struggle with heterogeneous CSV formatting, unobserved data hygiene defects (e.g., severe skewness, high missingness, duplicate rows, and outlier contamination), and the cognitive overhead of selecting appropriate algorithmic families. DataPulse AI is an autonomous, production-grade tabular dataset profiler, heuristic machine learning task recommender, and generative AI platform engineered to resolve these bottlenecks.

Addressing the assigned Continuous Assessment problem statement P10 (CSV Dataset Insight & Task Recommender), the application realizes five interconnected units (U1–U5) combining deterministic statistical computation with modern generative modeling. In U1, the system ingests arbitrary CSV files via robust delimiter sniffing, computes per-column parametric and non-parametric distributions, calculates an objective 100-point Data Health Score, classifies the target into Supervised (Binary/Multiclass Classification or Continuous Regression) or Unsupervised paradigms, and formulates a tailored 7-stage ML lifecycle blueprint. In U2, an intelligent natural language code assistant leverages large language models (Google Gemini API with a local Ollama fallback) to write and execute pandas transformations; arbitrary code execution risks are neutralized through a dedicated Abstract Syntax Tree (AST) visitor that enforces strict syntactic whitelisting and rejects dangerous system operations.

To uncover latent semantic relationships, U3 embeds column names and contextual schema definitions into a high-dimensional vector space using Sentence-BERT (all-MiniLM-L6-v2) to perform hierarchical column clustering, while an integrated multimodal Vision LLM inspects rendered statistical charts to extract analytical commentary. In U4, a deep tabular generative model based on PyTorch Conditional WGAN-GP (CTGAN) synthesizes realistic synthetic tabular samples, empirically benchmarked against ground truth distributions using two-sample Kolmogorov-Smirnov (KS) tests and correlation delta Mean Absolute Error (MAE). Finally, in U5, an automated Responsible AI governance suite scans for Personally Identifiable Information (PII) leaks and identifies severe class imbalances with prescriptive re-sampling remediation strategies.

DataPulse AI was empirically validated across three public benchmark datasets—Iris Flower (Botanical, Health 99.0/100), Titanic Passenger Survival (Maritime Demographic, Health 90.5/100), and Wine Quality (Physicochemical, Health 83.4/100). Backed by a complete 40-test automated Pytest verification suite achieving a 100% pass rate, the application demonstrates deterministic reproducibility, defensive sandbox integrity, and zero-hallucination factual consistency.

1 Introduction

Generative Artificial Intelligence has revolutionized unstructured data domains such as natural language processing, computer vision, and synthetic audio generation. However, in enterprise, financial, medical, and scientific analytics, the vast majority of actionable business data remains fundamentally tabular—structured in relational tables and Comma-Separated Values (CSV) formats. Despite decades of advancement in relational databases and machine learning libraries, the initial exploratory phase of data science remains fraught with manual friction, subjective heuristics, and security risks.

In standard machine learning workflows, a data scientist presented with an unfamiliar CSV file must perform a repetitive series of diagnostic procedures: inspecting column data types, identifying missing values, computing central tendency and dispersion statistics, plotting marginal distributions, diagnosing skewness and outliers, determining whether the business problem corresponds to classification, regression, or unsupervised clustering, and verifying that the dataset does not leak confidential or protected attributes. This exploratory data analysis (EDA) phase is both time-consuming and prone to human oversight.

Limitations of Traditional Static Profilers

Traditional automated profiling utilities (such as Pandas Profiling or ydata-profiling) generate monolithic, static HTML reports that suffer from three structural drawbacks. First, they are passive: they display descriptive charts but fail to synthesize actionable algorithmic guidance, leaving model family selection entirely to manual guesswork. Second, they lack interactive semantic reasoning: users cannot interrogate the data through conversational queries or demand customized ad-hoc transformations without manually writing boilerplate code. Third, they offer zero generative or augmentation capabilities: when datasets suffer from severe class imbalances or privacy constraints preventing cloud sharing, legacy profilers cannot synthesize privacy-preserving tabular rows or benchmark distribution fidelity.

The Generative AI Paradigm for Tabular Data

DataPulse AI bridges this divide by orchestrating a tripartite synergy of artificial intelligence paradigms:

  • Deterministic Heuristic Profilers: Rapid, mathematical computation of missingness penalties, IQR outlier bounds, and parametric normality checks that provide grounded, non-hallucinated data hygiene scores.
  • Large Language Model (LLM) Reasoning: Utilizing advanced frontier LLMs (Google Gemini API with local Ollama fallback) to generate precise pandas transformation scripts from natural language queries, accompanied by contextual narrative interpretations.
  • Deep Tabular Generative Modeling: Deploying a Conditional Tabular Generative Adversarial Network (CTGAN) implemented in PyTorch to synthesize realistic, non-memorized tabular rows that preserve multi-column correlations and marginal distributions.

Engineering Philosophy & Defensive Security

Allowing an LLM to generate and execute code dynamically within a production web runtime introduces severe threat vectors, chiefly arbitrary remote code execution (RCE) and system inspection. A core engineering contribution of DataPulse AI is its defense-in-depth Abstract Syntax Tree (AST) validation sandbox. Rather than relying on fragile keyword blacklists, the system inspects the Python parse tree before execution, blocking unauthorized system calls, filesystem writes, and introspection dunders. The resulting platform delivers high analytical agility while maintaining uncompromising operational security.

IQR = Q3 - Q1; Lower Bound = Q1 - 1.5 * IQR; Upper Bound = Q3 + 1.5 * IQR

To provide practitioners with an intuitive quality indicator, DataPulse AI calculates a deterministic 100-point Data Health Score:

Health Score = 100 - (Missing_Pct * 1.0) - (Duplicate_Pct * 0.5) - (Outlier_Pct * 0.2)

This deterministic scoring formula guarantees that identical datasets receive identical quality scores without LLM hallucinations.

6.2 U2 – LLM Code Assistant, AST Sandbox & Execution

Allowing non-technical users to query tabular datasets in natural language requires translating English questions into executable Pandas transformations. However, blindly passing LLM-generated code to Python's exec() function constitutes an egregious security vulnerability: an attacker or compromised model could run import os; os.system('rm -rf /'), read server environment variables, or exfiltrate private dataset records.

DataPulse AI resolves this challenge through a multi-tiered architecture combining prompt-constrained LLM generation, strict Abstract Syntax Tree (AST) validation, and a restricted execution runtime.

The AST NodeVisitor Security Guard

The modules/code_validator.py module inspects the parsed Python grammar before execution begins. It subclassess ast.NodeVisitor to enforce a strict zero-trust policy:

class SafeCodeVisitor(ast.NodeVisitor): FORBIDDEN_CALLS = {'open', 'eval', 'exec', '__import__', 'getattr', 'globals', 'locals'} FORBIDDEN_ATTRS = {'to_csv', 'to_sql', 'to_pickle', '__subclasses__', '__bases__'} def visit_Import(self, node): raise SecurityViolation("Explicit 'import' statements are strictly prohibited.") def visit_ImportFrom(self, node): raise SecurityViolation("Explicit 'from ... import' statements are strictly prohibited.") def visit_Call(self, node): if isinstance(node.func, ast.Name) and node.func.id in self.FORBIDDEN_CALLS: raise SecurityViolation(f"Dangerous function call '{node.func.id}' is blocked.") self.generic_visit(node) def visit_Attribute(self, node): if node.attr in self.FORBIDDEN_ATTRS: raise SecurityViolation(f"Forbidden attribute or write operation '{node.attr}' blocked.") self.generic_visit(node)

Sandboxed In-Memory Execution Runtime

If the code passes AST validation, safe_executor.py executes the script within an isolated global dictionary: {'df': df.copy(), 'pd': pd, 'np': np} with __builtins__ restricted to harmless primitives (print, range, len, sum, min, max). Standard output is captured via io.StringIO and displayed to the user alongside the transformed DataFrame slice.

6.3 U3 – Sentence-BERT Column Clustering & Vision LLM

Real-world enterprise datasets often contain redundant, correlated, or semantically duplicated columns created by disparate engineering teams (e.g., client_id vs customer_num; petal_width vs petal_length). Standard correlation matrices capture only linear numerical relationships, failing entirely when columns are non-numeric or differently scaled. DataPulse AI incorporates Sentence-BERT semantic feature embeddings to uncover latent schema affinities.

Sentence-BERT Semantic Clustering Pipeline

The modules/embeddings.py module constructs a rich contextual profile for each column combining its identifier, inferred data type, sample values, and statistical summary. These profiles are passed to a pre-trained Siamese neural network (sentence-transformers/all-MiniLM-L6-v2), which maps each feature into a 384-dimensional dense semantic vector space. Pairwise affinity is computed using cosine similarity:

Cosine Similarity(u, v) = (u · v) / (||u|| * ||v||)

Multimodal Vision LLM Chart Analysis

In addition to text embeddings, modules/vision_analyzer.py enables multimodal visual intelligence. When statistical distribution charts or correlation matrices are rendered, the system exports them as high-resolution in-memory PNG images. These image bytes are passed to Gemini Vision with an analytical prompt, enabling the model to directly "read" visual chart contours, identify multi-modal peaks, detect visual outliers, and comment on skewness patterns.

6.4 U4 – PyTorch CTGAN Tabular Generation & KS Benchmark

Tabular data generation poses formidable challenges for standard generative adversarial networks due to mixed data types, multimodal non-Gaussian distributions, and extreme categorical imbalances. To satisfy unit U4, DataPulse AI incorporates a deep tabular generative pipeline based on Conditional WGAN-GP (CTGAN) implemented in PyTorch (modules/ctgan_generator.py).

Mode-Specific Normalization & Conditional Sampling

Standard min-max normalization collapses on multimodal continuous features. CTGAN resolves this via mode-specific normalization: each continuous column is modeled using a Variational Gaussian Mixture (VGM) to derive Gaussian mode components. Each numerical value is transformed into a one-hot representation of its mode plus a scalar scalar indicating its representation within that mode. Discrete columns are one-hot encoded. A conditional vector is passed to both the Generator and Discriminator to ensure that minority classes are sampled adequately during training.

Figure 8 · PyTorch CTGAN tabular generation architecture and WGAN-GP training flow (U4). Mode-specific normalized features are trained via Wasserstein GAN with Gradient Penalty, enabling realistic synthetic sampling without memorization.

Statistical Fidelity Evaluation: Two-Sample KS Test

To verify that the synthetic rows accurately mirror the true marginal distributions without hallucination, synthetic_evaluator.py executes two-sample Kolmogorov-Smirnov (KS) tests across all continuous features:

KS Statistic D = sup_x | F_real(x) - F_synthetic(x) |

Values closer to 0 indicate near-identical cumulative distributions. On the Titanic dataset, CTGAN achieved a Mean KS statistic of 0.281 and a Correlation Delta MAE of 0.040, confirming remarkable distributional fidelity.

11 Limitations

An essential tenet of scientific rigor is transparency regarding systemic boundaries and observed operational constraints. DataPulse AI was developed to be honest about what its underlying models can and cannot mathematically guarantee:

1. CTGAN Compute Latency on Large Datasets

Conditional WGAN-GP training involves iterative gradient penalty computations and mode-specific variational Gaussian mixture fitting. While small datasets (Iris: 150 rows) train in ~2.5 seconds on CPU, datasets exceeding 50,000 rows require 3 to 10 minutes without dedicated GPU acceleration. On free-tier cloud containers (1 vCPU, 1 GB RAM), training on very large datasets can risk timeout or memory watchdog termination unless downsampled.

2. Conservative AST Security Constraints on Plotting

To maintain an impenetrable security boundary against arbitrary code execution, the AST visitor strictly blocks explicit import statements and plotting framework execution (e.g., import matplotlib.pyplot as plt; plt.show()). Consequently, user queries in the Code Sandbox are restricted to DataFrame aggregations, filtering, and statistical summaries; visual plotting is handled exclusively through pre-built UI components.

3. Ephemeral Cloud Storage & Session Volatility

Streamlit Community Cloud operates on stateless container infrastructure. Datasets uploaded by users, generated synthetic CSVs, and trained CTGAN neural weights exist only in ephemeral container memory. When a browser tab is refreshed or a container restarts after inactivity, cached artifacts must be regenerated.

4. Semantic Disambiguation of Uncontextualized Acronyms

Sentence-BERT maps natural language meanings into dense vector space. When presented with highly cryptic enterprise column headers lacking descriptive names or data dictionary metadata (e.g., x12_flg, f_39b), cosine similarities revert to superficial subword character matching rather than true domain semantics.
